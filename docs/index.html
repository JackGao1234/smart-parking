• 新北交通：新北市政府資料開放平臺 — 路外公共停車場登記資訊 (data.ntpc.gov.tw)
• 桃市交通：桃園市政府資料開放平台 — 路外停車資訊即時空位 API
• 台中交通：臺中市政府資料開放平臺 — 公／民營路外停車場總表與即時燈號 API
• OSM圖資：OpenStreetMap Nominatim 公開地圖停車場地標（無即時剩餘格數連線，作為補充圖資）
